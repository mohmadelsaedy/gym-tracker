# رفعة: سجل تمارين الجيم

تطبيق ويب لتسجيل تمارين الجيم: روتينات، تايمر راحة، أرقام قياسية، ورسوم تقدم.
بيشتغل من غير إنترنت، وممكن يتضاف للشاشة الرئيسية زي أي تطبيق.

## الرفع على GitHub Pages
1. اعمل repository جديد على GitHub (مثلاً `rafaa`)، وخليه Public.
2. ارفع كل الملفات دي في الـ repository (Add file ← Upload files).
3. روح Settings ← Pages، واختار Branch: `main` والفولدر `/ (root)`، ودوس Save.
4. بعد دقيقة أو اتنين هيبقى التطبيق على: `https://USERNAME.github.io/rafaa/`

## البيانات
كل التمارين بتتحفظ على المتصفح نفسه. من تبويب "التقدم" تقدر تعمل تصدير لنسخة احتياطية وتستوردها على أي جهاز.
